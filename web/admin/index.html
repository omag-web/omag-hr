What Pip always does (can't be edited here)
These rules are built into Pip's code so they can't be removed by accident:
  • Says it's an AI assistant provided by OMAG, not OMAG staff and not a lawyer.
  • Searches the statute library and reads the actual sections before answering legal questions.
  • Cites only sections it actually read; unverified citations are removed automatically.
  • Never presents itself as legal counsel.
  • Never repeats personal details back. Social Security, card, account and license numbers and birth dates are removed before a message reaches the AI or is saved.
  • Uses the member's selected form of government and its Title 11 starting points.

Document templates

OMAG's Word documents that members fill in and download, such as the personnel policy and FMLA policy. Upload a Word file with {{fields}} where answers go; Pip finds them and asks members those questions. Members see the templates that are switched on.

How to make or update a template

Open the Word file and type a field name in double braces wherever a member's answer should go, for example {{municipality_name}} or {{pay_period}}. Names use lowercase letters, numbers and underscores. Then upload the file here; Pip adds a question for each new field, and you can write the question and help text.

  • {{sick_wait_months | words}} prints a number as words (3 → three). Use | Words for a capital letter, | upper, | lower or | title for case.
  • {{#offers_comp_time}} … {{/offers_comp_time}} around paragraphs includes them only if the member answers Yes. {{^offers_comp_time}} … {{/offers_comp_time}} includes them only for No. Put these tags on their own lines.
  • Always available without a question: {{form_label}} (e.g. Statutory Town), {{unit}} (Town or City), {{governing_body}}, {{today}}, {{year}}.
  • Upload one file for every form of government, or separate files per form (a Town version and a City version, say). Charter cities get the Council-Manager file if there isn't a Charter one.
  • Unanswered questions print as a blank line (________) so the document can be finished by hand.

Edit sources on GitHub ↗
How to change an address or add a law
  1. Click Edit sources on GitHub (sign in to GitHub if asked).
  2. Change the "url" for an Oklahoma title, or copy an entry to add one. Federal parts are listed by "title" and "part" (for example 29 and 825); their address is built automatically.
  3. Click Commit changes…, then Commit changes. GitHub rebuilds the library, which takes about 5 minutes (watch it here ↗). If anything is wrong, the build stops and Pip keeps the library it has.
  4. Come back here and click Check for updates now.

Admins

People who can sign in here. Every admin can see and change everything: conversations, messages, instructions, documents and settings.

Invite an admin

They get an email from no-reply@verificationemail.com with a temporary password, good for 7 days. Tell them to check Junk.

What the buttons do

Resend invite: for someone who hasn't signed in yet, or whose 7 days ran out. Sends a new temporary password.

Reset password: for someone who's locked out. Emails them a code; they use "Forgot password?" on the sign-in page.

Turn off: they can't sign in, and are signed out within a minute. Reversible.

Remove: deletes their account. To add them back, invite them again.

You can't turn off or remove yourself.
